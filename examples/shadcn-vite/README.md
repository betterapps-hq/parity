# React + TypeScript + Vite + shadcn/ui

An example Vite app with React, TypeScript, and shadcn/ui's Nova style on Base UI, generated by
[`@buildkitgg/shadcn-sync`](https://github.com/betterapps-hq/buildkit/tree/main/packages/shadcn/shadcn-sync).

## Using components

Installing runs `shadcn-sync`, which builds every shadcn component into a `@buildkitgg/shadcn` package in
`node_modules/.buildkit/shadcn`. Import components from it:

```tsx
import { Button } from "@buildkitgg/shadcn"
```

`src/index.css` imports the package's Tailwind stylesheet, so its classes and theme load with the app's own.
