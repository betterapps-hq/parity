# Relay (vite-fluent-pnp)

Example app G for Parity: React 19, Vite 7, TanStack Router with code-based routes, Fluent UI v9 styled with Griffel,
Fluent icons, TypeScript and Storybook, installed by Yarn with Plug'n'Play, so it has no `node_modules`. Its own
components, in `src/components`, are built from Fluent's.

```bash
yarn dev
```
