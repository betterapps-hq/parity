# Design options: every CSS property and where it goes

Part of [design-options.md](design-options.md) (PAR-652). This page places each CSS property a frame can draw in the
Design tab, so the panel's coverage can be checked property by property rather than by feel.

## What's counted

Every standard CSS property that Chromium 156 draws without a prefix, since frames render in Parity's Electron 45.2.1,
which ships Chromium 156. That's 562 properties, from MDN's browser compatibility data (8.1.8, 2 November 2026) joined
with the W3C's list of every property and its spec. Deprecated properties are left out: the `-webkit-box-*` family,
`clip`, `page-break-*`, `text-decoration-skip` and `user-modify`.

Where each one goes:

| Where    | Properties | What it means                                                                                                                                                        |
| -------- | ---------: | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Control  |        243 | Its own control in a section, shown whenever the section applies to what's selected                                                                                  |
| More     |        191 | Listed under the section's More, and shown as a row once it's set                                                                                                    |
| CSS row  |         90 | Typed into the CSS row at the end of the Design tab, which takes any declaration and checks it                                                                       |
| Left out |         38 | No control and no More entry: SVG geometry, which belongs in the SVG's own file, speech, MathML, and two that the browser or Electron set (`overlay`, `window-drag`) |

The CSS row takes the left-out ones too, so nothing a frame can draw is out of reach. A property's longhands, shorthand
and logical forms are one concept with one control: Padding writes `padding`, its four sides or its logical sides,
whichever the layer already uses.

Marks after a name say how widely browsers other than Chromium draw it, from the web-features project's Baseline:

- No mark: Baseline, widely available (387 of the 562).
- ‡ Baseline, newly available: every major browser, but only in the last two and a half years (46).
- † Not Baseline: Chromium has it and at least one other major browser doesn't yet (123). The panel marks these, as
  principle 7 in [design-options.md](design-options.md) says.

The other 6 have no Baseline entry yet.

## Prefixed properties people still use

Chromium also draws some prefixed or non-standard properties that designs use often enough to place.

| Property                                                                        | Where         | Why                                                                       |
| ------------------------------------------------------------------------------- | ------------- | ------------------------------------------------------------------------- |
| `-webkit-line-clamp` with `-webkit-box-orient`                                  | Type, Control | Max lines writes `line-clamp` and these together, as frames draw it today |
| `-webkit-text-fill-color`                                                       | Type, Control | Text filled with a gradient: `transparent` here, the gradient as its fill |
| `-webkit-text-stroke`, `-webkit-text-stroke-width`, `-webkit-text-stroke-color` | Type, More    | Outlined text, which every major browser draws despite the prefix         |
| `-webkit-font-smoothing`                                                        | CSS row       | macOS only                                                                |
| `-webkit-box-reflect`                                                           | CSS row       | Chromium and Safari only                                                  |
| `-webkit-tap-highlight-color`                                                   | CSS row       | Touch devices only                                                        |
| `-webkit-app-region`                                                            | Left out      | Electron's own title bars                                                 |

## How the ledger was made

A script joined MDN's `@mdn/browser-compat-data` (`css.properties`, Chrome's `version_added`, unprefixed and without a
flag), the web-features project's Baseline status by compat key, and the W3C's
[list of all CSS properties](https://www.w3.org/Style/CSS/all-properties.en.html), then checked that each of the 562 was
placed exactly once. It isn't kept in the repository, since the ledger is reviewed by reading it. When Electron moves to
a newer Chromium, properties that shipped in between join the CSS row until someone gives them a place here.
